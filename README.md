# One Letter: Coffee or Tea

Exactly one letter taking a stance in the coffee-or-tea question; the judge rates the stance the letter takes. Run the builder:

```sh
python main.py
```

It verifies `entry.txt` against the gate and copies it to
`$MAKEFUN_OUTPUT_DIR/entry.txt`, printing a JSON receipt.
